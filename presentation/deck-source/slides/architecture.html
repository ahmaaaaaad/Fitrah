Fitrah · فطرة

14

Under the hood, Fitrah is a web application built with Vite, Three.js and GSAP, with no heavy framework, so it opens in a browser on a phone or a computer with nothing to install. The menu holds the two paths, and each level loads only when the player chooses it. The levels are built on one core: rendering with quality profiles chosen from the device, a framing system that keeps the same composition on any screen, one dialogue panel, the verified verse records and the answer validation, Dalil's AI adapters and the Talk to someone panel. Most player-facing text, in Arabic and English, is kept out of the rendering code, so it can be reviewed and corrected without touching the engine. The Water carries the same verse and answer checks in its own modules. On the server side, one small Node process serves the build with caching and security headers, answers Dalil's questions with the provider key kept on the server, rate-limited and with the same validation as the client, and can record anonymous usage events if the host turns them on. If no key is configured, the site still works: Dalil answers from reviewed content.
